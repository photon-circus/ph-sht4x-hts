# Code of conduct

## The short version

Be straightforward and be kind. Argue with the work, not the person.

## Expected behavior

- Assume competence and good faith. Ask what someone meant before telling them
  they are wrong.
- Give feedback about the change: what it claims, what evidence supports it,
  what it costs. Not about who wrote it.
- Accept feedback the same way. A rejected proposal is a normal engineering
  result, and a recorded rejection is more useful than a silent one.
- Say what you actually verified, and say plainly when you did not verify
  something. Overstated confidence wastes other people's time and, in a device
  driver, other people's hardware.
- Respect the boundary this repository has drawn. Disagreeing with it is fine;
  say so and make the argument.

## Unacceptable behavior

- Harassment, intimidation, or discrimination of any kind, including in private
  channels connected to this project.
- Personal attacks, demeaning comments, or persistent disruption of discussion.
- Publishing someone's private information without permission.
- Sustained pressure to accept a change after a maintainer decision, or
  relitigating a settled decision without new evidence.
- Presenting unverified claims as verified, or hardware behavior as established
  when only a host model was exercised. In this repository that is a conduct
  issue as well as a technical one, because the value of the evidence record
  depends on everyone reporting honestly.

## Scope

This applies in every project space — issues, pull requests, discussions,
commit messages, and code review — and whenever someone is representing the
project elsewhere.

## Reporting

Report a concern privately through this repository's **Security** tab using
**Report a vulnerability**, which is the available private channel; mark it
clearly as a conduct report rather than a vulnerability. If that is
unavailable, open a
[minimal contact request](https://github.com/photon-circus/.github/issues/new?title=Private%20contact%20requested&body=Private%20contact%20requested.)
in the organization standards repository containing only the sentence "Private
contact requested," with no detail.

Reports are handled privately. The reporter's identity is not shared without
their consent.

## Enforcement

The maintainer will respond in proportion to the behavior: a private
correction, a public correction, temporary restriction from project spaces, or
a permanent ban. Enforcement decisions are recorded privately, and the person
affected is told what happened and why.

This project is small and solo-maintained. If the concern is about the
maintainer, raise it through the organization contact request above.
